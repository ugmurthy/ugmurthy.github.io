Getting started

Working in
60 seconds.

Install the CLI, add a provider key, initialize your local agent home, and run your first goal.

01

Install AdaptiveAgent
macOS / Linux
curl -fsSL https://github.com/ugmurthy/adaptiveAgent/releases/latest/download/install.sh | sh

Use the signed release installer. It places the CLI binary locally and prints any required PATH update.

02

Add your provider key
terminal
export OPENROUTER_API_KEY="<your-key>"

OpenRouter is the default quickstart. Mistral, Mesh, and local Ollama providers are also supported.

03

Initialize and run
terminal
adaptive-agent init
adaptive-agent doctor --provider-check
adaptive-agent run "Hello, confirm you are working"

Your first run is durable and inspectable—not a disposable chat response.
